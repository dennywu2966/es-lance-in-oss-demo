## Codebase Patterns

- **Python script pattern in Node.js**: Use heredoc syntax (`python3 - <<'PYEOF'\\n${script}\\nPYEOF`) to execute Python code from TypeScript files. Remember to clear proxy environment variables before importing Python libraries.
- **OSS credentials management**: OSS credentials are read from environment variables (OSS_ACCESS_KEY_ID, OSS_ACCESS_KEY_SECRET, OSS_BUCKET, OSS_REGION). Never hardcode credentials in frontend code.
- **API route structure**: All API routes use `app/api/[resource]/[action]/route.ts` pattern with POST handlers that return JSON responses with `{ success: boolean, ... }` structure.
- **Error handling**: Always wrap Python execution in try-catch blocks with cleanup of temp directories using `fs.rm(tempDir, { recursive: true, force: true })`.
- **Elasticsearch integration**: ES uses Basic auth (base64-encoded credentials), bulk API expects NDJSON format (newline-delimited JSON), dense_vector field requires exact dimensions, cosine similarity is default metric.
- **Lance dataset operations**: Extract vectors with `.as_py().tolist()` pattern, use `dataset.to_table(columns=[...])` for selective loading, always cleanup temp directories after operations.
- **Performance tracking**: Use `Date.now()` before and after each phase to build timing breakdowns. Store timing as `{ phase: string, duration: number, startOffset: number }` array for waterfall visualization.
- **Component composition**: Create reusable visualization components (like WaterfallTimeline) that accept data props and handle their own animations and styling with Framer Motion.
